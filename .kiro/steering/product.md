# Product

AgentReady helps developers inspect a public GitHub repository for structural signals that make coding-agent work easier: overview, agent instructions, tests, CI, build manifests, architecture, contributing guidance and .gitignore.

A browser-only heuristic produces a 0–100 score and prioritized recommendations. It checks file paths, not document contents or actual test quality. Describe detections as "present/detected", never proof of security, correctness or agent effectiveness.

Keep this small: no database, login, cloning or paid LLM calls. The app's runtime does not invoke Kiro. Preserve responsive, accessible usage and the existing public API flow.
