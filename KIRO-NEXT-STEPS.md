# Kiro University — next steps

This repository intentionally does **not** contain challenge lesson evidence yet.

The Kiro University terms require meaningful Kiro usage and a `.kiro` folder that demonstrates the required lesson capabilities. Use this project as the functional starting point, then create the challenge-specific material with Kiro itself before submitting.

Suggested workflow once Kiro credits are available:

1. Open this repository in Kiro.
2. Work through the seven official lessons and use each capability on this project.
3. Let Kiro create/update the relevant `.kiro` artifacts rather than copying pre-generated challenge evidence.
4. Make at least one meaningful product improvement with Kiro (for example, deeper manifest inspection, authenticated GitHub access, exportable reports, or repository comparison).
5. Run `npm test` after changes.
6. Verify the app still works with `npm start`.
7. Commit the resulting `.kiro` folder and lesson-specific work.
8. In the final submission, describe truthfully how each Kiro lesson was used.

Do not submit this base repository as evidence of Kiro lesson completion by itself.
